# Farha Kousar Portfolio

A futuristic, terminal-inspired personal portfolio website built with HTML, CSS, and JavaScript.

## Overview

This project is a cyberpunk-style portfolio for Farha Kousar, designed to feel like a command-line interface or hacker terminal. It showcases personal branding, projects, experience, skills, certifications, and contact information in a visually engaging and interactive format.

## Features

- Terminal-inspired dark UI with neon green accents
- Animated matrix-style background and scanline effects
- Glitch text, live clock, and futuristic ID-card layout
- Project cards and skill tags
- Experience, certifications, and service highlights
- Interactive chatbot panel
- Retro mini-game UI
- Responsive layout for desktop and mobile screens

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — main portfolio page and styling
- `README.md` — project documentation
- `LICENSE` — MIT license

## Run Locally

You can view the site by opening `index.html` directly in a browser, or serve it locally:

```bash
git clone https://github.com/FarhaKousar1601/Farha-Kousar-portfolio.git
cd Farha-Kousar-portfolio
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customize

To personalize the portfolio:

- Update the text content in `index.html`
- Replace the contact links and social URLs in the contact section
- Adjust the project list, skills, and certifications to match your profile
- Modify the colors and animations in the CSS to suit your branding
